The ten .woff2 files in this directory are a redistribution of five typefaces,
all licensed under the SIL Open Font Licence 1.1. The OFL permits that only
if the copyright notice and the licence travel with the files, so this is that
file. It is served from /fonts/OFL.txt alongside them.

They were fetched by `site/tools/fetch_fonts.py`, which subsets them to latin
and latin-ext. Subsetting makes these Modified Versions under the licence's
definition; none of the five upstreams declares a Reserved Font Name, so no
renaming is required, and every notice below is reproduced verbatim from
upstream.

That last point is load-bearing rather than decorative. The design this site's
second face is built from specifies IBM Plex Sans, whose notice reads
`Copyright © 2017 IBM Corp. with Reserved Font Name "Plex"`. Clause 3 of this
licence forbids a Modified Version from using a Reserved Font Name, and the
paragraph above states that these files are Modified Versions — so Plex could
not ship here under that reading. Inter fills the same role and reserves
nothing. The substitution is a licensing decision, not a typographic one.

The first two families dress the original site; the last three dress the
second.
