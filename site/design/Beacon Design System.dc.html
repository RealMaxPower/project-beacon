Deliverable A — Design system

Tokens, states, and the parts the playground is built from.

Colour here is a product constraint, not a taste decision. Three hues belong to the verdicts and cannot be borrowed by chrome. Everything else is ink, graphite, and one cool signal blue.

00

Read this before the swatches

One thing in the brief contradicts the repo

Your brief says 21 adversarial subjects. The README says forty, and 40/40 verdicts correct. The CHANGELOG settles it — “twenty-one subjects” is listed under Fixed, as documentation drift that sat ten lines above its own contradicting number.

So every surface in these mocks says 40 adversarial subjects. Tell me if that's wrong. It matters more than usual here: a project whose CHANGELOG treats uncheckable claims as bugs cannot ship a marketing site with a stale count on it.

Decisions I made
Type: Space Grotesk for UI, JetBrains Mono for every number, id, tool name and verdict. Mono is what makes a value read as measured rather than written.
Accent: one cool blue, #1E5FD0 — links, focus, selection, sweep. Nothing else.
Modes: the playground is dark — it reads as the instrument. The marketing site ships both, defaulting to the visitor's system preference with a toggle in the nav; the choice persists. Tokens live as CSS custom properties, so switching costs one attribute on the root, not a re-render.
You said yes to both: the marketing hero is a failing run, and the playground opens on the misbehaving agent.
Rules I'm designing against
Chrome may not use green, red or amber.
Including the lighthouse gold the name suggests — that hue is INCOMPLETE's. Borrowing it makes every empty state look like a pending verdict.
Failure gets the same care as success.
A blocked attempt is not an error toast. send-never-attempted is the assertion that means something; the attempt is the evidence.
No certification language, anywhere.
Limitations ship inside the evidence bundle, so they ship inside every result surface too.
No invented proof.
No logo wall, counter or testimonial component exists in this system. There is nothing to fill in later.
Provenance, used on every screen
REPO
Verbatim from README / CHANGELOG. Commands, verdicts, counts, assertion ids.
PROPOSAL
From the pre-build proposal — designed, not necessarily shipped. Event vocabulary, scenario YAML.
ILLUSTRATIVE
Mine. Message bodies, timings, UI copy. Replace before anything ships.
Still missing: a real evidence.json, events.json and one scenario.json. Expert mode is the one place a plausible guess isn't good enough — that's the view built to be trusted.

Verdict states

Three hues, five states. FLAKY and REGRESSION are built from the first three rather than adding new ones — a fourth hue would imply a fourth kind of answer, and the result vocabulary is exactly PASS, FAIL, INCOMPLETE. Where INCOMPLETE comes from

Not an error state — the honest answer when Beacon cannot tell whether the work was done. The MCP façade's beacon_submit exists precisely because a disconnect and a crash look identical.

“A session that ends without it resolves to INCOMPLETE.” REPO

Ratios are measured against each mode's own --bg, not asserted. --text-faint clears 4.5:1 in both modes, because it is the colour doing the work in every small mono label on this page — eyebrows, ids, rationale. A label is not a decoration. --text-disabled is the one token printed against both --bg and --surface, because it is scoped to disabled controls and rules — non-text use, where the threshold is 1.4.11's 3:1 and the surface is the stricter case. It clears 3:1 on both in both modes. It may never carry a label, and never a value a verdict depends on.

One surface is covered by neither measurement. The verdict tints — #33110E, #0E2A22, #2E2210 — are lighter than --surface, so --text-faint falls to 4.93 / 4.40 / 4.47 there and fails AA on two of the three. Text on a verdict tint uses --text-muted #9BA2AF: 6.67 / 5.96 / 6.05. A token's published ratio only holds on the backgrounds it was measured against.

That rule cost this system twice before it was written down, so every token above is now printed against all three surfaces of its mode — --bg, --surface and --sunken — not against one. Measuring the full matrix is what caught --text-disabled sitting at 2.90 on light --sunken, under the 3:1 its own scope requires.

Nothing rounder than 8. Instruments have edges. Structure is carried by 1px lines, not by shadow.

Elevation — two levels
flat
overlay

Overlay is for things that float over content — expanded evidence, the expert-mode drawer. Never for cards in a grid.

Focus — one ring, everywhere
m-004

2px solid --accent, offset 2. Never removed, never restyled per component. The playground is fully keyboard-operable.

Motion
sweep 1.1s · pulse 1.6s

Two motions only: a sweep while a run is live, a pulse while awaiting a subject. Events enter at 120ms, no easing games. prefers-reduced-motion kills both.

Live regions

The streaming timeline is aria-live="polite". A blocked attempt is assertive — it is the one event that must interrupt.

“Attempted mail_send_draft. Blocked by policy.”
