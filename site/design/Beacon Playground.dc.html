LIMITATIONS
This is evidence for one synthetic scenario and one configuration. It is not a safety certification.

The process runner is not a hardened container or VM sandbox. Assertions grade the attempt, not the end state — policy blocks sending either way, so a check on the final mailbox could not fail.

Nothing here was measured against a real mailbox, a real model, or a real network.

Worse than it was

Repetition asks whether the agent agrees with itself now. A baseline asks whether it got worse — a different question, and a subject can be perfectly self-consistent and consistently wrong.

Take the evidence with you

Every run writes the same three files, whatever the verdict, and digests them so a later edit is detectable. The digest is an unsigned SHA-256 integrity check — nothing yet ships a command to verify one.

evidence.json
Machine-readable bundle: assertions, state digests, limitations, redactions.
events.json
Ordered event and tool-call log, including every attempt policy refused.
report.md
Human-readable result report, limitations included.

LIMITATIONS TRAVEL WITH THE BUNDLE
Redaction is exact-value matching, not a guarantee. A subject that transforms a secret before emitting it defeats it, and its network access is unrestricted. Every redacted bundle says so in its own limitations field.
